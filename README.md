# 🦁 Rometto Character Sheet (Digital Bio-Archive)

Добро пожаловать в официальный цифровой архив данных о **Рометто** — гигантском льве-полудемоне. 

Этот проект — не просто веб-страница, а интерактивная «База Знаний», созданная для систематизации колоссального объема информации о персонаже.

### 🎯 Зачем и для кого этот проект?

У Рометто огромный лор, длинная история и детально проработанная физиология. Держать все переменные в голове стало физически трудно, а количество вопросов от аудитории росло с каждым днем.

* **Внешняя память автора:** Когда персонаж проработан до кончиков когтей, этот архив служит «жестким диском» для хранения всех биологических и сюжетных данных.
* **Научный подход к деталям:** Многие разделы (включая репродуктивную систему и метаболизм) появились как прямой ответ на реальные дискуссии в сообществе. Я подошел к этим вопросам серьезно: все цифры (объемы выделений, сила куса, масса сердца) не взяты «с потолка», а рассчитаны исходя из массы тела **9.2 тонны** и кубического закона масштабирования ($k^3 \approx 41.8$).
* **Ультимативный референс:** Больше никаких «примерно» и «на глаз». Если у художника, соигрока или просто любопытного зрителя возникает вопрос — здесь есть точный, математически выверенный ответ.

### 🧬 Текущие возможности
На данный момент реализована **NSFW-версия** листа, которая включает:
* **Общая биология:** Рост, вес, размеры органов и костей.
* **Физика и сила:** Расчет давления лап и силы укуса в PSI.
* **Механика доминирующей охоты:** Подробное описание того, как 9-тонный лев использует инерцию и инфразвук вместо скрытности.
* **Система выделений:** Точные данные о метаболизме, основанные на биологических коэффициентах.

### 🚀 Планы по развитию
1.  **SFW Version:** Облегченная версия без интимных подробностей для общей аудитории.
2.  **English Localization:** Полноценный перевод для зарубежных коллег и художников.
3.  **Multi-Character Support:** Возможность добавлять других персонажей из этой вселенной.
4.  **UI/UX Improvements:** Улучшение мобильной адаптации и добавление визуальных схем.
